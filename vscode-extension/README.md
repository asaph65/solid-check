# SOLID-Check Assistant

L'assistant VS Code officiel pour la librairie **SOLID-Check**.

## Fonctionnalités

- **Analyse en temps réel** : Détecte les violations SOLID à la sauvegarde.
- **Feedback visuel** :
  - 🟠 Soulignement Orange : Fichiers > 100 lignes.
  - 🔴 Soulignement Rouge : Fonctions > 20 lignes.
- **Quick Fix** : Ampoule pour "Refactoriser avec SOLID-Check".

## Pré-requis

Cette extension nécessite que `solid-check` soit installé dans votre projet ou globalement.
